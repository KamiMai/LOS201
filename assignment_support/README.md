# Shared ARM assignment environment

The original LAB01 kernel disables POSIX_MQUEUE and HIGH_RES_TIMERS. This
Linux 5.15 image enables them and uses ARMv7 compiler flags explicitly.

To rebuild, obtain the official Linux 5.15 source archive (kernel.org), set
KERNEL_TARBALL to that archive and run:

```bash
bash assignment_support/scripts/build-kernel.sh
```

The script needs an ARM GNU hard-float cross toolchain, kernel build tools,
Python 3 and gzip. Kernel source and intermediate build trees are not tracked.
To use an already built tree instead:

```bash
KDIR=/absolute/path/to/linux-5.15 bash assignment_support/scripts/build.sh
```

Images reuse the LAB03 BusyBox and ARM runtime libraries. Their upstream
licenses remain under the repository third-party notices. No HOST kernel is
replaced, and no experimental sensor module is loaded into the HOST.

Run from a full checkout:

```bash
bash assignment_support/scripts/run-qemu.sh 1
bash assignment_support/scripts/run-qemu.sh 2
```

Exit QEMU with Ctrl+A, X when no measurement is running, or `poweroff -f`
in the guest. Test scripts load modules explicitly. Reports are generated by
reports/build_reports.py using ReportLab, DejaVu fonts and the retained logs.
